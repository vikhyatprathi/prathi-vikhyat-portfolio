# Prathi Vikhyat — Portfolio

A responsive React + Vite portfolio using the information from the supplied resume.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Personalize before publishing
- **Portrait:** Replace the portrait placeholder in `src/App.jsx` with your own professional photo. Put it in `public/` and use an `<img>` element.
- **LinkedIn / GitHub:** Replace the generic profile URLs in the Contact section with your actual profiles.
- **Project links:** Add verified GitHub repositories, demos or screenshots if available.
- **Experience dates:** Confirm the date formatting for the Head of Operations role before publishing (the resume states January 2020–2021).
- **Education:** The details and scores are transcribed from the supplied resume.
- **Certifications:** Titles are transcribed from the supplied resume.

## Deploy
Build with `npm run build`. Deploy the generated `dist/` folder to Vercel, Netlify or GitHub Pages.

## Accuracy
Portfolio content is based on the supplied resume. No unprovided social links, project URLs or portrait have been invented.
